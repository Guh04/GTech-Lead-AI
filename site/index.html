Perguntas frequentes

Antes de decidir

Preciso ter domínio e hospedagem?

Não precisa ter nada pronto. Orientamos como registrar o domínio no seu nome e onde publicar, para a página ser sempre sua.

Eu consigo pedir alterações depois?

Sim. Os ajustes incluídos e as condições para mudanças futuras ficam descritos na proposta.

A página aparece no Google?

Preparamos título, descrição e estrutura para facilitar a busca. O tempo para aparecer varia, e não prometemos posição específica.

Como funciona o pagamento?

As condições são combinadas por escrito na proposta, antes de começarmos.

O que acontece com os dados enviados pelo formulário?

O formulário apenas abre o seu WhatsApp com a mensagem pronta. Este site não guarda nenhum dado digitado.
